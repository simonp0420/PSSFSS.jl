# Guidance for coding agents

## Project and working practices

PSSFSS is a Julia package for periodic planar polarization and frequency selective surfaces. It uses a method of moments with modified Rao-Wilton-Glisson (RWG) basis functions, stratified-medium Green functions, and generalized scattering matrices (GSMs).

Read relevant source and tests before editing. Check `git status` and preserve existing user changes. Make focused changes consistent with nearby Julia code. Avoid unrelated reformatting. Do not introduce dependencies, change public APIs, or regenerate manifests unless necessary for the requested task; explain any necessary change. Do not commit or push without user authorization.

## Repository map

- `src/PSSFSS.jl`: analysis orchestration and electric/magnetic GSM excitation and solve loops.
- `src/Sheets.jl`: `RWGSheet`, geometry, connectivity, and cached face integrals.
- `src/RWG.jl`: modified RWG data, periodic edge pairing, and Fourier transforms.
- `src/Meshsub.jl`, `src/structuredtri.jl`: triangulation.
- `src/FillZY.jl`, `src/Zint.jl`, `src/PGF.jl`: assembly and integrals.
- `src/Modes.jl`: Floquet mode selection.
- `src/AutoMeshRefine.jl`: charge and centroid-current reconstruction; AMR starting point.
- `test/AutoMeshRefine_test.jl`: focused analytic charge/current tests.
- `test/runtests.jl`: full test entry point using SafeTestsets.
- `docs/TheoryDocs/theorydoc.tex` and its included chapters: mathematical reference. Chapters 2, 6, and 7 cover modes, GSM excitation/extraction, and MoM. A compiled PDF is available too.

## Environment and validation

Run commands from the repository root with the project activated. Use a Julia runtime compatible with the selected environment. When this guidance was created, the local root manifest was generated by Julia 1.13.0, while CI covered Julia 1.10, 1.11, and 1.12. The local manifest does not establish the package's minimum supported version. Check current Project.toml, manifests, and CI before deciding compatibility.

Focused charge/current tests:

```sh
julia --project=. -e 'include("test/AutoMeshRefine_test.jl")'
```

Full package tests (test-only dependencies are declared in `test/Project.toml`):

```sh
julia --project=. -e 'using Pkg; Pkg.test()'
```

Use focused tests while iterating. Broaden testing when geometry, basis setup, assembly, or analysis is affected, and before declaring integrated AMR complete. Report exact validation scope and any failures or unverified results. Do not call a focused run a full-suite pass.

Prefer independent analytic expectations over comparing implementations of the same algorithm. Check continuity-equation charge, analytic RWG current, integrated charge conservation, dimensional scaling, complex linearity, periodic phases, and output overwrite. Retain the existing loop-order comparison as an additional consistency check.

Distinguish sandbox/dependency failures from numerical test failures. Do not alter dependencies or package code solely to bypass the execution environment. Disclose temporary loader workarounds and keep them out of the repository. Tests with an in-memory implementation replacement do not validate the unchanged implementation. Persistent REPL/Revise sessions can speed iteration; use a fresh process for final validation when retained state could matter.

## Numerical conventions

- Modified RWG current contributions are `I * (r-r_plus)/(2A_plus)` and `-I * (r-r_minus)/(2A_minus)` on plus/minus triangles, with periodic phases where applicable. Do not insert the conventional RWG edge-length multiplier. For electric surface-current modeling, the coefficient `I` has units of amperes and represents the signed total current crossing the defining edge on the plus triangle. On a periodic counterpart, apply the corresponding sign and Floquet phase. The electric-current impedance matrix `Z` has units of ohms.
- For magnetic surface-current modeling, the expansion coefficient has units of volts and represents the signed integrated magnetic current across the plus-side defining edge, with the corresponding sign and Floquet phase on its counterpart. The magnetic-current admittance matrix `Y` has units of siemens.
- The existing continuity convention is `rho = (im/omega) * div(J)` for electric sources and `rho_m = (im/omega) * div(M)` for magnetic sources. The same reconstruction algorithms apply to both; coefficient units determine the output units. Preserve signs consistently with code and theory.
- Coordinates use `sheet.units`; electric surface current reconstruction is in A/m and electric charge density is in C/m^2; magnetic surface current is in V/m and magnetic charge density is in V*s/m^2 (Wb/m^2). Convert lengths to metres when using SI areas and material constants. Use supported PSSFSS length units; RWGSheet does not accept every Unitful length unit.
- `sheet.fe[k, face]` is the edge opposite `sheet.fv[k, face]`. Preserve this relationship when rebuilding connectivity.
- Verify periodic phase signs against RWG.jl. Charge/current reconstruction uses `cis(-psi)` on the corresponding upper-boundary half-bases; phase fields use Unicode subscripted names.
- `tricurrent!` evaluates at triangle centroids. Its output elements are immutable `SVector{2,ComplexF64}` values. `fill!` with a zero SVector is safe; broadcasting that SVector into a vector of SVectors is not equivalent.

## AMR design context

The intended first estimator is current-weighted charge discontinuity (CWCD), based on Kim and Peterson, with electric- and magnetic-current sheets both in scope. Consult the equations themselves:

- Kim's 2017 dissertation, Chapter 5, equation (5.7): EFIE-type combined estimator.
- Evaluation of Local Error Estimators for the RWG-Based EFIE, equation (5): published CWCD and normalization.
- Adaptive h-Refinement for the RWG-Based EFIE, equation (7): area-weighted marking and neighbouring-cell footprint.
- Adaptive h-Refinement for the RWG EFIE Applied to Targets With Edges: singularities and refinement control.

The dissertation and published CWCD use different normalization. CWCD adds a current term to a charge jump; it is not current magnitude multiplied by charge discontinuity. The agreed initial interpretation uses centroid currents dotted with testing vectors carrying a length factor. Describe this as a discrete estimator interpretation, not exact line integration or a certified error bound. Do not silently switch to path integration.

Keep reconstruction, indicators, excitation aggregation, marking, mesh changes, and convergence criteria distinct. Triangle-area weighting is an optional marking strategy for managing edge singularities, not part of raw CWCD. The proposed initial GSM aggregation is a cellwise maximum of separately normalized indicators across all retained TE/TM excitations from both Gblock sides, including evanescent modes. This is a proposal, not an implemented feature or a guarantee for arbitrary coherent superpositions.

Translate and phase-adjust periodic neighbours into a common frame. Physical metal boundaries need an explicit treatment and are distinct from periodic seams. Preserve matching periodic boundary edges during refinement. Rebuild RWG data and invalidate mesh-dependent integral, Fourier, and matrix caches after changing geometry/connectivity. Solve loops reuse RHS buffers: evaluate or preserve currents before the next excitation overwrites them.

Electric- and magnetic-current AMR share reconstruction, periodic handling, excitation aggregation, and refinement machinery. For the homogeneous-medium CWCD weights, use electromagnetic duality: replace the electric current factor `k*eta` with `k/eta` and the electric charge factor `1/epsilon` with `1/mu` for magnetic sources, with consistent normalization. Existing reconstruction docstrings describe electric units; extend documentation and validation for magnetic units as the feature develops. Material weighting between unlike media, normalization near zero response, and stopping criteria remain design questions. State assumptions and resolve mathematically significant choices with the user. Validate AMR against converged complex scattering parameters as well as indicators. Record evolving mathematical decisions in a design note and update this guidance when agreed conventions change.
