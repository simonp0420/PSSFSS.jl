Symmetric Pixelated Element

For a pixelated element created with the sympixels function, one should always specify 'M' for the element class. This is discussed in the "checkerboard" usage example.

p1 = plot(sheet, linecolor = "red", unitcell=true)
p2 = plot(sheet, linecolor = "blue", lw=0.35, rep = (3,3))
plot(p1, p2, layout = (1,2), size=(800,400))
